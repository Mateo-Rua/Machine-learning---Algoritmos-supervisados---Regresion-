Este repositorio contiene proyectos prácticos enfocados en la implementación de algoritmos de regresión supervisada utilizando Python. Cada proyecto aborda problemas específicos, demostrando cómo aplicar técnicas de regresión para analizar datos y realizar predicciones basadas en características relevantes. El objetivo es explorar distintos enfoques, desde el preprocesamiento de datos hasta la evaluación de modelos, en una variedad de contextos y conjuntos de datos.


## Archivos en el repositorio

1. **Predecir_precios_casas.ipynb**: Un Jupyter Notebook que incluye la implementación paso a paso del modelo de regresión, el preprocesamiento de los datos, y el análisis de los resultados. Este archivo permite reproducir los experimentos realizados para entrenar y evaluar el modelo.
2. **house_prices.txt**: Archivo de texto con el conjunto de datos utilizado en el proyecto. Incluye características de las propiedades como el número de habitaciones, superficie, año de construcción, entre otros.

## Objetivo del proyecto 1

El objetivo principal es desarrollar modelos de regresión que permita predecir los precios de casas con base en múltiples características. Esto incluye:
- Exploración y preprocesamiento del conjunto de datos.
- Selección de características relevantes para el modelo.
- Entrenamiento y evaluación de modelos de aprendizaje supervisado.
- Análisis de resultados y ajuste fino de los parámetros del modelo.

## Requisitos

Para ejecutar el proyecto localmente, asegúrate de tener instaladas las siguientes dependencias:
- Python 3.x
- Bibliotecas: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `optuna`
